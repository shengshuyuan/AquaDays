# AquaDays V3 · 透明水景

2026-11-06。针对 V2 水体平、缺乏通透感的反馈重做美术。当前版本在 prototype/，原型页面刷新即可查看。

水景由内置 imagegen 原创生成，源图为 water-source.png。背景集成时实际缩放到 240×250，转为 RGB565，静态放在 240×320 的完整界面里。水面反光、侧玻璃、光照、水草远近与沙底细节均烘焙在背景里，运行时不计算折射或动态光照。

鱼沿用原创精灵，增加细小亮部与鱼鳍透明度；RGB565A8 导出保留中间透明度，已预生成成鱼与左右朝向。当前鱼身仍偏简化像素造型，后续可以继续单独精修，不把背景质量等同于鱼的美术完成度。
