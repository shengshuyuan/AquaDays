# AquaDays 像素交互稿 V2

日期：2026-11-06。此稿替代 V1 的高分辨率 AI 美术概念，当前设计以 V2 为准。V1 保留供回溯。

## 这次交付什么

- `aquadays-pixel-v2-board.png`：四个页面，每页原生 240×320，无美术缩图。
- `home-240.png`：原始像素主页；`home-3x.png`：最近邻 3 倍放大，未补充任何细节。
- `select-240.png`、`feed-240.png`、`clean-240.png`：三个交互状态。
- `aquadays-live-v2.gif`：同一渲染器生成的 12 秒动画；2 倍整数放大，12 次/秒模拟步进，不代表真机帧率。
- `../../../prototype/`：无运行依赖的 HTML + Canvas 交互原型；所有游戏画面严格绘制在 240×320 画布中，颜色按 RGB565 量化。

## 画面与操作

鱼缸的水体、水草、石头、沙底和光束为静态像素背景。鱼使用 32×24 精灵、3 帧摆尾；幼鱼 1 倍、成鱼 2 倍整数显示。时间与日期占用上部固定区域，鱼的游动范围避开该区域，保持数字完整可读。气泡、鱼食和藻点是少量简单图形。

主页上下选择「喂食 / 擦缸 / 选鱼」，短按确定执行，长按确定返回。浏览器额外提供鼠标按键与 Esc 返回，硬件本体无需额外按键。

选鱼先选品种，再选幼鱼 / 成鱼，确定后入缸。演示开局为一条琉金成鱼、一条兰寿幼鱼、一条琉金幼鱼；最多五条。首批仅展示金鱼品种，保留未来按真实体型、习性扩充的空间。

## 养鱼的趣味

1. **每天最多两份**：这一份未吃完不能再投，当天吃满后显示提示。投喂颗粒逐渐下落，每条鱼都有分配的食物，会靠近追食。
2. **吃到才成长**：每吃一颗，幼鱼进度 +2；到 24 后变成成鱼。按演示分配，每条鱼每天最多吃四颗，约三个照料日可长大。这是游戏时间，不对应现实生长周期。
3. **分区擦藻**：三处缸壁各有三个藻点，上下切换区域、确定擦一次，直到擦亮。重复擦干净区域不增加进度。
4. **照料章**：当天至少喂过一份且水质达到 90% 时记一枚，每天最多一枚。水质与成长保留可见反馈，不添加商店、金币或排行榜。
5. **不强迫死亡惩罚**：本原型没有生病、死亡和离线扣血。长期惩罚规则尚未获得用户选择，不在视觉设计阶段预设。

选种的识别重点是琉金高背与背鳍、兰寿圆背且无背鳍、鹤顶红白身红帽且有背鳍。形态参考 [Goldfish Society of America 品种指南（CAOAC 收录）](https://www.caoac.ca/post/the-goldfish-society-of-america-s-basic-breeds-guidelines)。像素图是原创简化表达，不是生物学图鉴，也不据此建议真实混养。

## 为什么这版有实现路径

实际资源已导出到 `prototype/assets/`，数据来自同一渲染器，非估算图尺寸：

| 资源 | 格式 | 实际字节 |
| --- | --- | ---: |
| 静态背景，240×320 | RGB565 | 153600 |
| 3 品种 × 3 帧 × 2 大小 × 2 朝向，共 36 帧 | RGB565A8，颜色平面后接透明度平面 | 207360 |
| 191 字点阵字库 | 1bpp | 2583 |
| 图像与字形位图合计 | 不含索引、代码与其他固件资源 | 363543（约 355 KiB） |

成鱼整数放大、左右翻转已烘焙进资源，不依赖运行时旋转、抗锯齿或全屏特效。RGB565A8 布局已对照相邻仓库的 LVGL 软件绘图实现，宽度为 32 或 64，颜色 stride 为宽度×2，透明度 stride 为宽度。`manifest.json` 记录每帧尺寸与偏移，`resource-audit.json` 记录大小。

固件建议将这些原始资源作为 const 放在 Flash，由 LVGL 图片对象引用，保持现有 240×20 单显示缓冲（9600 字节）。移动鱼和换帧只更新对应区域，不新增一个 240×320 的全屏 RAM 画布。时间、状态、字体与清洁区域分别绘制。此方案不需要 PSRAM，但尚未通过链接、堆内存与上板计时验证。

字体使用开源 [Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font) 的 12px 点阵子集，许可证在 `prototype/font-licenses/`，设备内文字不会依赖 macOS 字体。

## 验收方式与已执行检查

- 进入预览 → 主页非空，所有画布均为 240×320，RGB565 配色。
- 确定投喂 → 喂食计数增加且产生颗粒；吃完两份再按 → 配额与水质不再改变。
- 选品种与大小 → 对应鱼入缸；满五条 → 拒绝继续增加。
- 上下换清洁区并确定 → 擦除对应藻点、水质提高；重复擦 → 不重复发奖励。
- 长按确定 → 回到鱼缸，松开不触发额外喂食。
- 模拟日期前进 → 配额清零；日期不变或回拨 → 配额保持。
- 主机自检覆盖上述模型边界、成长、确定性运动、文字覆盖与导出资源格式。浏览器另检查可见按键、键盘路径和移动窗口布局。

完整执行记录见 `validation.md`。

## 尚不能据此承诺的部分

Build（固件）：NOT RUN。Host tests：见 validation.md。Device tests：NOT RUN。

未实现 ESP-IDF 应用入口、LVGL 适配、NVS 存档、Wi-Fi 校时、电源行为或真机功耗。设备完全断电后的时间来源需要联网或人工校准方案；未取得可信日期前不应重置每日配额。浏览器原型使用内存状态，刷新会重置，演示「下一天」和「重置」不是设备游戏按键。
