## 浏览器实际交互

工具：Ego Lite，通过 `ego-browser`。地址：`http://127.0.0.1:8791/prototype/`。

页面标题、非空内容、五个 240×320 画布正常，无框架错误遮罩；CDP 记录到的 JS exception 数为 0，原型错误列表为空。

实际路径：

- 点击「确定键」→ fed=1、出现 6 个颗粒、状态提示「开饭啦！」。
- 点击「下键」「确定键」→ 进入擦缸；再确定 → 擦除一块、提高水质。
- 键盘 Esc 返回，方向下与 Enter 进入选鱼；选兰寿与成鱼并确定 → 鱼数 3→4，新增鱼为兰寿成鱼。
- 选择大小时按住 Enter → 650ms 后返回主页；松开后喂食计数仍为 0，未触发额外确定。
- 使用 fed=2 的受控测试状态按 Enter → 颗粒保持 0、fed 保持 2，显示「今天吃饱啦，明天再喂」。
- 点击「演示：下一天」→ 日期 2026-11-06→2026-11-07，配额归零。
- 恢复动画并等待 age 增加 → 鱼的真实坐标改变，非静态截图播放。

桌面以 1252×854 视口检查；移动以 390×844 视口检查。移动版画布实际 CSS 尺寸为 240×320，文档宽度不超过视口，无横向溢出。截图见 `qa-desktop.png`、`qa-mobile.png`。
