## 视觉方向

1. 鱼缸主页：大小鱼、水草、浅色沙底、后景时间日期；底部仅显示饲食与水质的简短信息和三键入口。
2. 选鱼：真实鱼种大图、名称、体型提示、鱼缸容量和明确的入缸操作。概念稿鱼种仅作视觉示例，不据此确定混养规则。
3. 喂食：颗粒落下，鱼靠近；显示今日已用份数，达到上限后禁用继续投喂。
4. 清洁：局部缸壁藻点、小刷子、清洁进度；明确上下移动、确定擦除。
