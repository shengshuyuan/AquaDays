# V7 喂食与擦缸

背景、鱼种、游动不变。改的是喂食和擦缸的玩法与画面，让它们和通透的像素水景统一。截图由实际渲染器在 240×320 上生成，2×/3× 为最近邻放大。

## 擦缸：九格 → 三行

- 原来是 9 块藻点集中在右侧一列，上下键只能在同一竖列里换格，没法左右移动。
- 现在玻璃分为上、中、下三行（y 92–151 / 152–211 / 212–270，时钟区不脏）。上下键选行，确定擦一整行；擦完光标自动跳到下一行，所以连按三下确定就能擦干净。
- 选中的行四角用金色短角标标出，和底部选中按钮的金色下划线同一种语言。
- 擦的时候，刮水器从左到右扫过 0.7 秒，扫过的地方立刻变清；身后留两道斜向玻璃反光，1 秒内淡出。
- 脏的样子：整面玻璃一层淡绿薄雾，靠边框更浓；藻斑是不规则半透明小簇，偶尔有水渍圈。每行的斑点位置固定，每天看起来是同一面玻璃。水质低于 90% 时首页也会显示，越脏越明显。
- 夜晚所有污渍、刮水器、反光都按夜间色调压暗。

## 喂食：一条斜线 → 一小撮

- 原来 14 粒 2×2 的点从屏幕顶部排成斜线落下，匀速，停在半水中。
- 现在从水面一个随机位置撒下一小撮（左右约 40 像素内），在 0.8 秒里陆续入水；入水处有两道向两侧散开的水波。
- 鱼食有三种形状（2×2 粒、3×3 圆粒、3×2 片），带高光和阴影；入水时快、随后减速到各自的下沉速度，下沉时左右轻摆 1 像素。
- 没被吃掉的鱼食会落到沙面上静止，鱼可以游到缸底吃掉。鱼吃到时冒出一点碎屑。

## 尚存限制

- 薄雾、藻斑、反光用了半透明叠加；设备上需要逐像素混合，开销小但尚未实测。网页里半透明叠加的结果没有逐像素量化到 RGB565。
- 刮水器只是侧视的简单造型；擦的过程没有水滴。
